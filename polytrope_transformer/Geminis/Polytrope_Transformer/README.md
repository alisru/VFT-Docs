# Fractal Polytrope Sovereign LLM — Standalone Package

## Why the Google Drive HTML link looked like plain text earlier
When `.html` files are uploaded directly to Google Drive as documents, Google Docs strips out all `<script>` (JavaScript/Three.js) and `<style>` tags, turning an interactive web app into a wall of unformatted plain text.

## How to Run & Test the LLM Properly

### Option 1: Interactive Browser Console (Zero Install)
1. Unzip this archive (`polytrope_sovereign_llm_bundle.zip`).
2. Double-click **`polytrope_interactive_console.html`** to open it in Chrome, Firefox, Edge, or Safari.
3. Type any prompt, toggle negation polarity (`A -> ¬A`), test parables vs. modern policies, or audit legislative clauses with live 3D WebGL manifold rendering.

### Option 2: Local Python CLI
Run `polytrope_llm_cli.py` with Python 3 (zero external dependencies required):

```bash
python3 polytrope_llm_cli.py "The national government will build regional water reservoirs."
```

Or run it in interactive REPL mode:

```bash
python3 polytrope_llm_cli.py
```
