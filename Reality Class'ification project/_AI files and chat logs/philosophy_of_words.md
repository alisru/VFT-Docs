## 1. Words as Purpose-Built Problem-Solving Tools

A word is not an arbitrary label, a static definition, or an abstract linguistic convention. 

**A word is a purpose-built tool invented by an agent to solve a specific problem in reality.**

Even an *unknown* is a problem—a void in awareness that causes hesitation, error, or danger. When an agent encounters an obstacle, friction, or deficit in the world, they experience **Strain**. To overcome that strain, they direct force along a vector (**Action**) to bring reality into a new equilibrium (**Effect**).

A word is the **crystallized residue of that intentional problem-solving process**.

```
[Problem / Tension in Reality]
              │
              ▼
    [Strain Experienced]
              │
              ▼
 [Action Vector Directed over Time]
              │
              ▼
   [Transformed Effect / State]
              │
              ▼
  WORD IS BORN (The Tool to Repeat, Coordinate, and Navigate that Transition)
```

## 2. The Genesis of Primitives from Human Necessity

Every root concept exists because a specific geometric or operational tension arose:

* **`open`**: Exists because an agent encountered a **boundary** blocking access to something they needed past, and applied force to part the barrier.
* **`close`**: Exists because an agent needed to **protect an interior** from outer intrusion or seal a container to prevent loss.
* **`shelter`**: Exists because an agent was exposed to **hostile incoming forces** and erected a barrier to remain intact.
* **`store`**: Exists because an agent experienced **surplus today and scarcity tomorrow**, inventing an enclosure to hold resources across time.
* **`know`**: Exists because **uncertainty and false assumptions caused catastrophic failure**, so agents verified observations to navigate reality safely.
* **`give` / `take`**: Exists because resources were **separated across distinct sovereign boundaries**, requiring custody transfer to balance deficits.
* **`live`**: Exists because stillness was broken by **motion striving continuously against decay**.
* **`die`**: Exists because **energy and integrity eventually exhausted**, halting motion into permanent rest.

## 3. The AE-C Equation: Action-Effect over Context

Because words are problem-solving tools, every word is mathematically structured as:

$$\mathbf{Word} = \big(\ \mathbf{Action} \;\xrightarrow{\mathbf{Strain}}\; \mathbf{Effect}\ \big)\ \Big\vert_{\ \mathbf{Context}}$$

### The Triad Components
1. **The Problem / Strain ($\vec{R}$)**: The resistance, obstacle, or initial state that demanded a solution.
2. **The Tool / Action ($\vec{F} \Delta t$)**: The directional vector of force applied over time to alter the state.
3. **The Solution / Effect ($\Delta S$)**: The resolved equilibrium achieved relative to the anchor.
4. **The Context ($Q_1 \dots Q_7$)**: The dimensional plane where the problem-solving tool is deployed.
