## 3. Long Description (Detailed Overview)

Tired of Google Gemini’s native "Export to Docs" feature turning beautiful LaTeX mathematical equations into blurry, static, and un-editable images? 

The **Gemini LaTeX Docs & Markdown Exporter** is a lightweight, privacy-focused extension that restores full data accessibility and formatting integrity to your exports. It replaces temporary visual KaTeX elements with standard LaTeX formatting and exports them directly to your destination of choice.

### Key Features:
*   **True LaTeX Equation Recovery:** Instantly converts rendered chat equations back into clean, editable LaTeX syntax using standard inline (`$ ... $`) and display block (`$$\n ... \n$$`) markers.
*   **One-Click Google Docs Export:** Creates a new Google Doc in your Google Drive, parses formatting, and opens it automatically in a new tab. No copy-pasting required!
*   **Instant Markdown Download (.md):** Export responses locally. The custom HTML-to-Markdown engine formats headings, bold/italic text, numbered/bulleted lists, GFM tables, code blocks (with language tags), and equations into clean Markdown.
*   **Premium Native UI Integration:** Adds two unobtrusive, glassmorphic buttons directly inside Gemini's native "Share & export" overlay menu. Includes sleek, slide-up toast status alerts.
*   **Brave and Chrome Compatibility:** Engineered using the standard OAuth2 web auth flow, bypassing native profile sync blocks to work flawlessly on Brave, Chrome, Edge, and other Chromium browsers.
*   **Security & Privacy First:** 
    *   The Google Docs integration only requests the `drive.file` OAuth scope, meaning the extension can *only* create new files and access files it created. It has zero access to the rest of your private Google Drive files.
    *   The Markdown downloader runs 100% offline, keeping your data entirely local on your machine.
