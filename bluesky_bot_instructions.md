# Bluesky Bot Instructions & Protocol

## 1. Operating Rules
- **DO NOT EXECUTE LIVE POSTS WITHOUT EXPLICIT PERMISSION.** Always run dry runs, show the output to the user, and wait for a clear "go" before running the script.
- **Stay Under the Character Limit:** Bluesky posts are strictly capped at 300 characters. The Python script uses a dynamic `split_text` function to automatically chunk longer texts at spaces/newlines.
- **Clean URLs:** Always strip tracking query parameters (e.g. `?at_medium=RSS...`) from URLs to save character space.

## 2. The Core Engine: The 5-Phase Convergence Test Protocol
The bot MUST rigorously execute the 5-Phase Convergence Test protocol for every judgement:

### Phase 1: Structural Scan (The 7 Planes)
The 7 Interrogatives MUST map strictly to the 7 Planes of Actualism in this exact order:
1. **Q1 — WHO (Metaphysical)**: Will and Direction (Stated beneficiary vs actual beneficiary)
2. **Q2 — WHAT (Possible)**: Faith and Probability
3. **Q3 — WHERE (Physical)**: Matter and Distance (Concrete physical landing/impact)
4. **Q4 — WHY (Lyrical)**: Meaning and Resonance
5. **Q5 — HOW (Logical)**: Count and Consistency (Method/Execution)
6. **Q6 — CAUSE (Historical)**: Sequence and Causality (Origin/History)
7. **Q7 — EFFECT (Emotive)**: Passion and Consequence (Cumulative effect)

Track each as [P: n×mag, F: n, B: n] and note Phantom Fills.

### Phase 2: Vector Verification (Coordinates & Scale of Benefit)
The bot evaluates coordinates across Morality (Scope of Benefit) and Will (Scale of Activity vs Suppression):

**Morality Scope of Benefit:**
- `+2`: Everyone / all beings
- `+1`: Other beings (plural)
- `+0.5`: Other being (singular)
- `0`: No-one / neutral
- `-0.5`: My group (exclusive in-group)
- `-1`: Me (self only)
- `-2`: Me, no-one else (active extraction)

**Will Scope of Activity:**
- `+2`: Maximum activity
- `+1`: Active
- `+0.5`: Partially active
- `0`: Stasis
- `-0.5`: Partially suppressing
- `-1`: Suppressing
- `-2`: Maximum suppression

Also calculate `z` (Ambiguity volume / blank total) and `R_net` (Integrity Score).

### Phase 3: Source Integrity (Hypocrisy Gap)
Calculate `ΔH` = ‖ Vector_Ideal − Vector_Action ‖. Does the actor apply the same standard to themselves?

### Phase 4: Forensic Stress Test
Test for **Fake Maximiser** (Capacity >> Effort, but problem remains unsolved to justify existence) and **Helxis** (Bait beneficiary ≠ Switch beneficiary).

### Phase 5: Verdict & Trajectory Mapping
Plot the transition from the *Stated Claim* coordinates to the *Actual Action/Reality* coordinates:
- **Path of Grace:** `1,-1 -> 1,1`
- **Path of Redemption:** `-1,-1 -> 1,-1`
- **Path of Deception:** `-1,1 -> -1,-1`
- **The Fall / Empty Mass:** `1,1 -> -1,1`

## 3. Convergence Test Thread Template
A proper Convergence Test is a structured logical thread mapping the 5 Phases:

Must include the image generated by `generate_graph.py` (which now plots both Claim and Reality points and the Path).
```

ASSERTION: [The specific claim made]
VERDICT: [Pass / Conditional / Fail]
COORDS: CLAIM (u: X, psi: Y) -> REALITY (u: X, psi: Y)
```
