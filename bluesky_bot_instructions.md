# Bluesky Bot Instructions & Protocol

## 1. Operating Rules
- **DO NOT EXECUTE LIVE POSTS WITHOUT EXPLICIT PERMISSION.** Always run dry runs, show the output to the user, and wait for a clear "go" before running the script.
- **Stay Under the Character Limit:** Bluesky posts are strictly capped at 300 characters. When calculating this, remember that URLs count towards the limit.
- **Clean URLs:** Always strip tracking query parameters (e.g. `?at_medium=RSS...`) from URLs to save character space.

## 2. Convergence Test Thread Template
A proper Convergence Test is an 8-post thread.

### Post 1 (Root)
Must include the image generated by `generate_graph.py`.
```
CONVERGENCE TEST: [Specific News Event]
SOURCE: [Clean URL]
ASSERTION: [The specific claim made by the system being tested]
VERDICT: Fails n1 — Plane Error.
COORDS: (υ: X, ψ: Y)
```
*Note: Use ASSERTION, not DEFINITION. We are testing a testable claim, not providing a dictionary definition.*

### Post 2-5 (The 7 Interrogatives)
Group the 7 interrogatives across 4 posts. Each must contrast "Claim" with "Evidence".
```
WHO
Claim: ...
Evidence: ...

WHERE
Claim: ...
Evidence: ...
```
(Continue for WHAT, WHY, HOW, CAUSE, EFFECT. Include Convergence/Divergence count at the end of the EFFECT post).

### Post 6 (Truth and Lie)
```
THE UNAVOIDABLE TRUTH: [What output the system actually produces reliably]

THE UNAVOIDABLE LIE: [The system's stated intent that the evidence contradicts]
```

### Post 7 (Plane Error)
```
PLANE ERROR: The state claims to operate on the [Stated Plane]... It actually operates on the [Actual Plane]...
```

### Post 8 (Vector Justification)
Justify why the (υ, ψ) coordinates were chosen.
```
VECTOR JUSTIFICATION:
Morality (υ): [Value]. [Explanation based on Universal vs Self benefit].
Will (ψ): [Value]. [Explanation based on Creative vs Destructive will].
```

## 3. Scripts
- `fetch_news.py`: Grabs top news from a public RSS feed.
- `generate_graph.py`: Generates the Psochic Hegemony graph (`dry_run.png`) based on the given (υ, ψ) coordinates. Uses inverted X-axis (left is positive, right is negative).
- `post_thread_bsky.py`: Logs into `@judgement-bot.bsky.social` using `atproto` SDK, creates the 8-post thread with the image, extracts link facets, and posts.
