# Bluesky Bot Instructions & Protocol

## 1. Operating Rules
- **DO NOT EXECUTE LIVE POSTS WITHOUT EXPLICIT PERMISSION.** Always run dry runs, show the output to the user, and wait for a clear "go" before running the script.
- **Stay Under the Character Limit:** Bluesky posts are strictly capped at 300 characters. The Python script uses a dynamic `split_text` function to automatically chunk longer texts at spaces/newlines.
- **Clean URLs:** Always strip tracking query parameters (e.g. `?at_medium=RSS...`) from URLs to save character space.

## 2. The Core Engine (Actualism Variables & The 7 Planes)
Regardless of the specific subject being tested, the generation logic MUST rigorously apply the core source ideals of the Convergence Test. The 7 Interrogatives MUST map strictly to the 7 Planes of Actualism in this exact order:

1. **Q1 — WHO (Metaphysical)**
2. **Q2 — WHAT (Possible)**
3. **Q3 — WHERE (Physical)**
4. **Q4 — WHY (Lyrical)**
5. **Q5 — HOW (Logical)**
6. **Q6 — CAUSE (Historical)**
7. **Q7 — EFFECT (Emotive)**

- **The Stated Ideal vs. The Actual Outcome:** The test must always juxtapose what the system claims to do (its stated intent) against what it reliably produces in reality.
- **The Plane Error:** The test must identify the divergence. Systems will typically claim to operate on the Logical plane (Q5 — mechanism for a stated output), but actually operate on the Metaphysical plane (Q1 — Will and Direction, prioritizing self-preservation or dominance).

## 3. Convergence Test Thread Template
A proper Convergence Test is a structured logical thread, which may dynamically split into more posts if character limits are exceeded.

### Post 1 (Root)
Must include the image generated by `generate_graph.py`.
```
CONVERGENCE TEST: [Specific News Event or Subject]
SOURCE: [Clean URL]
ASSERTION: [The specific claim made by the system being tested]
VERDICT: Fails n1 — Plane Error.
COORDS: (υ: X, ψ: Y)
```

### Post 2-8 (The 7 Interrogatives)
Group the 7 interrogatives across multiple posts using the exact Plane mapping. Each must contrast "Claim" with "Evidence".
```
Q1 — WHO (Metaphysical)
Claim: ...
Evidence: ...

Q2 — WHAT (Possible)
Claim: ...
Evidence: ...
```
(Continue for Q3 through Q7. Include Convergence/Divergence count at the end of the EFFECT post).

### Post 9 (Truth and Lie)
```
THE UNAVOIDABLE TRUTH: [What output the system actually produces reliably]

THE UNAVOIDABLE LIE: [The system's stated intent that the evidence contradicts]
```

### Post 10 (Plane Error)
```
PLANE ERROR: The system claims to operate on the Logical plane (Q5—mechanism for [stated output]). It actually operates on the Metaphysical plane (Q1)—specifically the will to [actual outcome/dominance].
```

### Post 11-12 (Optional MP Assessment / Isomorphism)
If requested or historically relevant, include an assessment mapping the current event to a historical isomorphism (e.g., comparing a modern socioeconomic siege to the 1941 Oil Embargo on Japan).
```
MP ASSESSMENT (ISOMORPHISM):
[Explanation of the recurring historical/metaphysical structure]

ISOMORPHIC REFERENCE:
[Specific historical event and how it reliably produced a specific outcome].
```

### Post 13 (Vector Justification)
Justify why the (υ, ψ) coordinates were chosen based on the actual outcome.
```
VECTOR JUSTIFICATION:
Morality (υ): [Value]. [Explanation based on Universal vs Self benefit].
Will (ψ): [Value]. [Explanation based on Creative vs Destructive will].
```

## 4. Scripts
- `fetch_news.py`: Grabs top news from a public RSS feed.
- `generate_graph.py`: Generates the Psochic Hegemony graph (`dry_run.png`) based on the given (υ, ψ) coordinates. Uses inverted X-axis (left is positive, right is negative).
- `post_thread_bsky.py`: Logs into `@judgement-bot.bsky.social` using `atproto` SDK, slices text to respect 300 char limits, extracts link facets, and chains the posts.
