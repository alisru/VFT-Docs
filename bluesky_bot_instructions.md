# Bluesky Bot Instructions & Protocol

## 1. Operating Rules
- **NEVER POST LIVE.** Always default to a dry run. The script must only output the text chunks to the console for the user to review.
- **Stay Under the Character Limit:** Bluesky posts are strictly capped at 300 characters. The Python script uses a dynamic `split_text` function to automatically chunk longer texts at spaces/newlines.
- **Clean URLs:** Always strip tracking query parameters (e.g. `?at_medium=RSS...`) from URLs to save character space.

## 2. The Internal Engine (The 5-Phase Convergence Test)
*Note: The bot uses this highly technical framework to calculate the results internally. The final public output MUST translate these results into plain English.*

1. **Phase 1: Structural Scan:** Map the 7 Interrogatives (WHO, WHAT, WHERE, WHY, HOW, CAUSE, EFFECT) against the Stated Claim vs. Actual Evidence.
2. **Phase 2: Vector Verification:** Calculate Coordinates.
   - **Morality (Benefit):** +2 Everyone, +1 Other beings, +0.5 Other being, 0 No-one, -0.5 My group, -1 Me, -2 Me, no-one else.
   - **Will (Action):** +2 Max activity down to -2 Max suppression.
   - **Coordinate Definitions:**
     - (+1.0, 0.0) -> Good Preference
     - (-1.0, 0.0) -> Bad Preference
     - (+1.0, +1.0) -> Greater Good
     - (-1.0, +1.0) -> Greatest Lie / Mask
     - (+1.0, -1.0) -> Lesser Good
     - (-1.0, -1.0) -> Greater Evil
3. **Phase 3: Source Integrity:** Calculate the Hypocrisy Gap between the stated ideal and actual action.
4. **Phase 4: Forensic Stress Test:** Identify Fake Maximisers (creating problems to solve them) and Bait/Switches (Helxis).
5. **Phase 5: Trajectory Mapping:** Plot the path from Stated Claim coordinates to Actual Reality coordinates (Grace, Fall, Redemption, Deception).

## 3. The Public Output Template (Plain English)
The final threaded output must be conversational, explanatory, and accessible. It must explain the news story clearly before delivering the judgement.

**DO NOT use hyper-technical jargon** like "z-profiles," "Helxis," "R_net," or "Q1q5c4" in the public text. Instead, translate these concepts into plain English (e.g., "Missing context," "Bait-and-switch," "Integrity breakdown").

### Post 1 (The Hook & Source)
Must include the image generated by `generate_graph.py`.
```
[Attention-grabbing opening summarizing the judgement, e.g., "A classic case of saying one thing but building another."]

Subject: [Subject / Article Title]
Source: [URL]
Evidence Standards: [State the standards used, e.g., "Stated ideal vs Actions within historical context"]
Verdict: [Pass / Fail] — [Name of Trajectory, e.g., The Path of Deception]
```

### Post 2-3 (The Subject at Hand)
A dedicated plain English explanation of what the news story or subject actually is, why it matters, and what the core issue is.
```
What's happening: [Clear, non-technical explanation of the news event or the system's actions. Give the reader context so they understand what we are judging.]
```

### Post 4: The Nuance (Bright Side / Poison)
**Crucial Rule:** Always find the nuance.
- If it's a negative/failing story, find the "bright side" or something genuinely good within it.
- If it's a positive/passing story, identify the "poison" or structural flaw hiding within it.
```
The Bright Side: [e.g., "The physical engineering teams are genuinely pushing boundaries and learning from failure."]
OR
The Poison: [e.g., "The system relies on temporary goodwill rather than structural safeguards."]
```

### Post 5-6 (The Claim vs. The Reality)
Contrast the stated intent with the actual outcome, explicitly stating the judgement coordinates.
```
The Claim: [What the actor/system says they are doing.]
Stated Judgement: [Coordinate and label, e.g., "(+1.0, 0.0) — Good Preference"]

The Reality: [What the evidence shows they are actually doing.]
Resulting Judgement: [Coordinate and label, e.g., "(-1.0, -1.0) — Greater Evil"]
```

### Post 6-7 (The Breakdown & Plane Error)
Explain the core failure or success using plain language derived from the 7 planes. Highlight the biggest contradictions, including the translated Plane Error and forensic tests.
```
The Breakdown & Plane Error:
[Explain the "Plane Error" simply. E.g., "The system claims its goal is to just logically update the software (HOW), but its actual structural effect is to assert total control over the marketplace (WHO)."]

[Explain the forensic tests simply. E.g., "It's a classic bait-and-switch: they hook you with the promise of 'universal connection', but the system is built to extract data strictly for their own benefit."]
```

### Post 8 (The Math & Trajectory)
Explain the coordinates and the graph simply.
```
The Trajectory: [Path Name]
They claim to operate for the Greater Good (+1.0, +1.0), but the structure actually operates purely for Self-Interest and Suppression (-1.0, -1.0).

When you map the gap between their stated intent and actual actions, it plots a direct path toward [Outcome / Terminal Zone].
```

### Post 9 (The Unavoidable Truth)
```
The Unavoidable Truth: [The harsh reality of the system's mechanics.]

The Unavoidable Lie: [The fiction the system relies on to keep operating.]
```

## 4. Scripts
- `generate_graph.py`: Generates the Psochic Hegemony graph (`dry_run.png`). Accepts Claim and Reality coordinates to plot the trajectory. Uses inverted X-axis.
- `post_convergence_test.py`: Runs a dry run of the threaded plain English post array.
