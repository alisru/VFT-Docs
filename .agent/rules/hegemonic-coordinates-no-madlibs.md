# Hegemonic Coordinate Semantics & Ban on Mad-Libs Template Text

* **Grounded Natural Human Sentences**: Every UI answer option, explanation, or scenario must be an authentic, grammatically complete human sentence that an everyday person would naturally speak or think.

## 3. UI Layout Normalization for Live Handles
* **Zero Jitter During Drag**: Coordinate telemetries, labels, and adjacent cards must use fixed-height layouts, CSS grid dimensions, or overflow constraints (`min-height`, `white-space: nowrap`, `text-overflow: ellipsis`). Changing string lengths during live handle dragging must never cause lines to wrap, boxes to expand/collapse, or the layout to jump.
