# Actualism Evidence Standard Rules

When running ANY convergence test or producing evidence standards, the following are HARD constraints.

## Required Standards (always in this order)
- [A] Stated ideal — what the actor claims to stand for, by their own words
- [B] Actions within context — what the actor actually does, relative to capacity and constraints
- [C] Objective ideal — what a structurally coherent, first-principles version of the stated goal would require

Additional standards [D], [E] etc. added only if needed.

## Hard Constraints on Every Fill
1. EVERY fill is STRICTLY 2 to 5 words. Exceeding this is a TASK FAILURE.
2. Every fill MUST describe a concrete, physical, observable reality — not an abstraction or academic summary.
   - CORRECT: "workers attacked in public space"
   - WRONG: "externalizing private security risks" — this is an abstract summary, NOT a physical event.
3. [B] in particular must be a concrete physical effect on the ground — what literally happened to real people or objects in real space.
