# Sources Verification Checklist

Tracks the verification status of every footnote tag in `Sources.md`, so future sessions don't have to re-derive what's already been checked or accidentally re-trust something that turned out to be fabricated. Update this file every time a citation is fetched and checked, whether it passes or fails.

Status key:
- ✅ VERIFIED — fetched directly this session or a prior session, quoted text confirmed present and correctly attributed. Archive file noted if one exists.
- ❌ FABRICATED / WRONG — fetched directly, quote or claim did NOT check out. Fixed in the doc; kept here as a permanent record so it's never reintroduced.
- ⚠️ FLAGGED — fetched, real source, but with a caveat (e.g. attribution uncertain).
- ⬜ NOT YET VERIFIED — footnote exists in Sources.md but has not been independently fetched and checked against its cited text this project.

## Bulk-archive script note (this session)
`fetch_archive.py` (in the `io` folder) fetches a URL and writes extracted page text straight to `Sources_Archive/<tag>.txt` via `requests` + `trafilatura`, without the page text passing through chat context — used to archive 32 of 36 remaining unverified sources in one batch, at basically zero token cost per page. TheyVoteForYou (3 tags) and AustLII both returned HTTP 403 to the scripted `requests` call (bot-blocked) but fetched fine through the `web_fetch` tool instead — all 4 archived and verified. Six pages flagged as thin/suspect (`onenation`, `onenation_tax`, `2gb19`, `onenation_aboriginalspend`, `phon22`) were then checked directly via Claude-in-Chrome browser-use (rendered JS): `onenation_tax`, `2gb19`, and `phon22` turned out to have real substantial text the script/web_fetch methods missed (JS-rendered content), now archived in full and marked ✅. `onenation_aboriginalspend` was confirmed to already be complete (807 chars was the whole real article, not a truncation). Only `[^onenation]` itself remains ⚠️ — it's a genuine thin JS tile-grid hub page that redirects to `/issues`, with the real policy content living on each individual sub-page instead, so there's nothing more to extract from the hub page itself. **Archived is not the same as verified**: every remaining ⬜ row above still needs its actual text read against whatever node claim cites it before being marked ✅.

## How to use this file
Before citing an existing footnote as support for a fix, check its row here first. If it's still ⬜, don't assume it's good just because it's already in the document — fetch it and update this row. If it's already ✅ or ❌, you can trust that finding without re-fetching (unless a long time has passed and content may have changed, e.g. news sites that update articles).
