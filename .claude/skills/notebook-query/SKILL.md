### 3. Query Execution Protocol
To execute a query against a notebook:
1. Locate the Notebook ID corresponding to your target topic from the table above or the registry file.
2. Formulate a precise, context-rich prompt.
3. Use the NotebookLM MCP integration tools to submit the query:
   - Command: `notebook_query`
   - Parameters:
     - `notebook_id`: Target notebook ID string.
     - `query`: Your detailed question.
4. Integrate the returned synthesis, preserving source citations.
